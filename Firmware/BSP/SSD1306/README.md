# SSD1306 / u8g2 移植

SSD1306 与 INA226 共享 I2C1。传输是异步的，由 `Peripheral/I2C/i2c_api.c` 负责；
u8g2 仅用作帧缓冲渲染器。

- 分辨率：128x64，1 位，1024 字节帧缓冲。
- 字体：MiaoUI `font_menu_main_h12w6`，固定 6x12。
- 探测地址：先 `0x3C`，再 `0x3D`。
- 全屏刷新：通过共享的 I2C DMA 驱动分 8 个 128 字节页完成。
- 只有在 PD 供电稳定后才开始面板探测/初始化。
- 上线后仪表盘每 200 ms 刷新一次；帧缓冲写入失败同时作为热拔出检测，
  使面板回到探测模式。

## 5 + 5 仪表盘

64 像素高度被划分为五行 12 像素的行，行间有四条 1 像素分隔线。x=64 处的
竖直分隔线形成五个左侧槽位与五个右侧槽位。

左列：

1. 反白 `CH32X035` 横幅
2. `WELCOME`
3. 实测总线电压
4. 实测总线电流
5. PD 合同状态

右列：

按以下顺序选取最多五个 Source PDO：

`AVS > EPR Fixed > PPS > SPR Fixed`

同一类别内，最大电压更高者优先显示。紧凑面板列表中刻意省略
Battery/Variable PDO。

不要调用 `u8g2_SendBuffer()`。绘制到 `SSD1306_U8G2_Get()` 返回的对象中，
并通过异步 BSP API 刷新。
